## The two things worth knowing first

**There is no save button.** Anywhere. Chapter saves start after one second of stillness, or within three seconds
during continuous typing, plus storage latency. Leaving a chapter or switching to focus mode
flushes pending edits and waits for outstanding saves. If
InkWell ever cannot save, it says so on screen rather than failing quietly.

**Nothing leaves your device unless you export it.** InkWell has no account, no sync, and no
network permission at all — not "we choose not to use it", but the permission is absent from the
app on every platform. Your manuscripts live in a single encrypted file on this device. The only
way anything gets out is the Export screen, and it writes only where you point it.
