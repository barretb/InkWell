# Exporting your book

Export is the only way anything you have written leaves your device. It happens when you ask for it
and writes only where you choose.

Reach it from **Export** in the library, on a manuscript, or from inside a chapter.

## What you can export

| Choice | Produces |
|---|---|
| **The whole manuscript** | One file with every chapter in order. |
| **One file per chapter** | A numbered file per chapter, in a folder you pick. |
| **Just this chapter** | A single file — offered when you came from a chapter. |

Each is available as **EPUB** or **PDF**.

## Which format

**EPUB** is what e-readers and most publishers want. Text reflows to whatever screen and type size
the reader chooses, so it is the right format for reading and for submitting.

**PDF** is fixed-page. Choose it for printing, or for sending someone a copy that will look the
same everywhere.

## Images

Every image in your chapters is embedded in the exported file. The book stands on its own — mail it
to someone with nothing else attached and the pictures are there.

The descriptions you gave your images travel with them, so an exported EPUB is readable with a
screen reader.

## Where it goes

Choosing a format opens your device's own save dialog. InkWell suggests a file name from your
manuscript's title; change it to whatever you like. The file is written to the path you confirm and
nowhere else — no copy, no temporary file left behind.

For **one file per chapter**, you pick a folder instead. Files are numbered so they stay in reading
order:

```
01 - Snowfall.epub
02 - The Mill.epub
03 - The Ridge.epub
```

Afterwards the screen tells you where the file went, how many images it carries, and how large it
is.

## If an export fails

You will see an explanation and this line:

> Export failed. Your manuscript is unchanged.

That is accurate. Export only reads your manuscript; a failure cannot damage it. The usual causes
are a folder you do not have permission to write to, or a full disk.

## Before you delete anything

If you are about to use **Delete all app data**, export first. Deleting removes the key that
encrypts your writing, and after that nothing is recoverable — not from a backup, and not by
reinstalling. An exported file is an ordinary file on your device and is untouched by any of it.
